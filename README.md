# 机器学习项目实践 - SVM, KNN, 逻辑回归, 线性回归

## 运行环境
- Python 3.8+
- 安装依赖：`pip install -r requirements.txt`

## 数据准备
将老师提供的文件放入 `data/` 目录，并解压 mnist_split.zip 和 cifar10_images.zip。

## 运行
- 训练并保存 SVM Titanic 模型：`python train.py`
- 测试 SVM Titanic 模型：`python test.py`
- 运行全部任务（线性回归、KNN、逻辑回归、SVM）：`python main.py`

## 结果
所有输出文件保存在 `results/` 文件夹中。
